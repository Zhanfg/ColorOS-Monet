# Application semantic mappings

This directory is populated during the one-time runtime-v2 materialization from
the already reviewed text-only mappings for X, TIM, and Coolapk. It contains no
APK, DEX, native library, or copied application asset.

After materialization the expected layout is:

```text
components/app-mappings/x/*.tsv
components/app-mappings/tim/*.tsv
components/app-mappings/coolapk/*.tsv
```
