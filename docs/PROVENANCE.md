# Provenance

## Project-authored components

- Entire module base and installer/runtime shell scripts.
- Gradle configuration and GitHub Actions workflows.
- Color-resource generator and repository audit tools.
- Semantic color mappings for X, TIM, and Coolapk.
- ColorOS satellite vector and dynamic palette treatment.

## Compatibility inputs not redistributed

The initial mapping review used application packages supplied by the device owner. These packages are not part of the repository or release source archive.

Earlier third-party ColorOS, Scene, and WeChat overlay APKs are deliberately excluded. Features represented only by those binaries are not part of the clean-room baseline until an independent implementation is available.
