# Experiment: OPlus homepage native-Expressive glyph alias RRO

The current ColorOS 17 Settings APK contains both:

- OPlus homepage glyph resources such as `settings_about_device_ic`;
- Android 17 native Expressive resources such as
  `ic_settings_about_device_expressive`.

The public tool:

`experiments/build_settings_native_expressive_alias_rro.py`

builds a local, unsigned RRO by aliasing only rows marked
`NATIVE_EXPRESSIVE` in:

`compat/coloros17/settings_oplus_homepage_icons.tsv`

No OPlus/Google artwork is copied into the repository or generated by the tool.
The RRO references the already-installed target package resources directly.

## Why experiment-only

The OPlus homepage preference classes already own two-tone tint/container
behavior. Replacing the inner drawable source may be correct, but the final
visual composition must be verified on-device before this can become a shipping
layer.

The experiment therefore:

- does not ship in the module;
- does not touch OEM-specific rows;
- does not use Material Symbols yet;
- does not activate automatically;
- does not alter the Settings native Expressive gate.

This is a controlled bridge for testing the exact native glyph source without
reintroducing package-wide card/list hooks.
